# Projeto-Agrinho-2026-----Gazeta-Cecpemar---Final
O projeto " Gazeta Cecpemar " é a simulação de um jornal digital, feito para informar e ajudar alunos que competirão no concurso agrinho, assim como informar e conscientizar alunos e professores que não irão participar
